- Import your passwords straight from Chrome, Edge, Brave, Firefox, Safari, Bitwarden, 1Password, LastPass, KeePassXC, Dashlane or Proton Pass. Export them as a CSV, open it in Import, and Lockbox deletes the CSV for you afterwards.
- New: auto-type (Windows). Turn it on in Settings, then press Ctrl+Alt+A on a sign-in page and Lockbox types your username and password. Nothing goes through the clipboard.
- Every login also gets an Auto-type button that types it into the window you were just using.
- Use more than one vault? Pick it with one click from the new Recent vaults list on the unlock screen.
- Opening Lockbox while it's already running now brings that window forward instead of starting a second copy.
- Update notes like these now show with proper formatting.
- Screen readers can now name every button and text box.
